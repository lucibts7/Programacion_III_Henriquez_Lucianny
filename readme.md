📚 Tecnologías y Conceptos Clave

A lo largo de la materia exploraremos las siguientes tecnologías esenciales para el desarrollo web moderno, abarcando desde las bases del frontend hasta el desarrollo avanzado del backend:

1. 🌐 HTML (HyperText Markup Language)

Es el lenguaje de marcado estándar utilizado para estructurar el contenido de las páginas web. Define la jerarquía y semántica de los elementos mediante etiquetas (párrafos, encabezados, imágenes, formularios, etc.).

2. 🎨 CSS (Cascading Style Sheets)

Es el lenguaje encargado del diseño visual y la presentación de los documentos HTML. Permite aplicar estilos como colores, fuentes, layouts responsivos (Flexbox, Grid) y animaciones para mejorar la experiencia de usuario.

3. ⚡ JavaScript (JS)

El lenguaje de programación fundamental de la web. Otorga dinamismo e interactividad a las aplicaciones web en el navegador, permitiendo la manipulación del DOM, manejo de eventos y peticiones asíncronas.

4. 📐 TypeScript (TS)

Un superconjunto (superset) de JavaScript desarrollado por Microsoft que añade tipado estático opcional y características avanzadas de programación orientada a objetos, mejorando la mantenibilidad y reduciendo errores en proyectos de gran escala.

5. 🟢 Node.js

Un entorno de ejecución (runtime) para JavaScript fuera del navegador, basado en el motor V8 de Google. Permite construir herramientas de consola y servidores backend escalables y de alto rendimiento utilizando eventos y I/O no bloqueante.

6. ⚛️ ReactJS

Una biblioteca de JavaScript desarrollada por Meta para construir interfaces de usuario interactivas y reactivas mediante el uso de componentes reutilizables y un DOM virtual eficiente.

7. 🦁 NestJS

Un framework progresivo de Node.js estructurado en TypeScript para construir aplicaciones del lado del servidor eficientes y escalables. Utiliza arquitectura basada en módulos, controladores y servicios, fuertemente inspirada en Angular.
